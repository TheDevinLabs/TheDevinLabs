# Contributing to Devin’ Labs

Thank you for contributing to Devin’ Labs.

---

## How to Contribute

### 1. Find an Issue
Look for:
- good first issue
- help wanted
- bug
- enhancement

---

### 2. Fork & Branch
Create a feature branch:

feature/your-change


---

### 3. Make Changes
- Keep changes small and focused
- Follow repository coding standards

---

### 4. Submit Pull Request
Include:
- What changed
- Why it changed
- Any relevant issue reference

---

## Rules

- One PR = one feature/fix
- No unrelated changes in a single PR
- Must pass review before merge
- Respect Maintainer feedback

---

## Code Style
Each repository may define its own rules.

Default expectation:
- Clean, readable code
- Minimal unnecessary complexity

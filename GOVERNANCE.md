# Devin’ Labs Governance Document

## Core Principle
Code belongs to its creators. Devin’ Labs provides infrastructure, not ownership.

---

## Roles

### 👑 Owner (Steward)
- Maintains organization infrastructure
- Defines ecosystem structure
- Oversees core repositories

Limitations:
- Does not own creator projects
- Does not override creator licensing

---

### 🧠 Creator
- Owns their project and IP
- Defines their own license
- Can join or leave Devin’ Labs freely

---

### 🛠 Maintainer
- Manages repositories
- Reviews and merges contributions
- Enforces technical standards

---

### 🤝 Contributor
- Submits pull requests
- Opens issues and suggestions
- Participates in ecosystem development

---

## Repository Types

### Core Repositories
Owned by Devin’ Labs (e.g., Doscript runtime)

### Creator Repositories
Fully owned by individual creators

### Community Repositories
Shared experimental projects

---

## Ownership Rule
Creators retain full ownership of their work at all times unless explicitly transferred.

---

## Decision Structure
- Owner: ecosystem direction
- Maintainers: technical execution
- Creators: project authority
- Contributors: implementation input
